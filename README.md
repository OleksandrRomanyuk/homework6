# Порівняння цін на комплектуючі для ПК

## Мета проєкту
Створення вебсторінки з таблицею для порівняння вартості основних комп'ютерних комплектуючих протягом 2023–2026 років. Мета проєкту — наочно продемонструвати зміну цін на відеокарту, процесор, оперативну пам'ять та SSD, а також відобразити загальне подорожчання комплектуючих.

## Використані технології
- **HTML5** — створення структури вебсторінки та семантичної таблиці з caption, thead, tbody, tfoot і відповідними заголовками.
- **CSS3** — оформлення таблиці, налаштування меж, внутрішніх відступів, кольорів рядків, центрування та контентного контейнера.
- **Normalize.css** — нормалізація стандартних стилів браузера.
- **@font-face** — підключення локального шрифту Montserrat у форматі WOFF2.
- **Fallback fonts** — використання системних резервних шрифтів на випадок недоступності основного шрифту.
- **Git** — контроль версій проєкту.
- **GitHub** — зберігання вихідного коду.

## Реалізовані вимоги
1. Створено контентний контейнер з обмеженою максимальною шириною та центруванням.
2. Підключено локальний шрифт Montserrat через @font-face.
3. Додано системний резервний шрифт Arial та sans-serif.
4. Реалізовано семантичну таблицю з назвою, заголовками стовпців і рядків та основними даними. Для заголовків використано атрибути scope="col" і scope="row".
5. Налаштовано межі таблиці, об'єднання меж, внутрішні відступи комірок та оформлення рядків.
6. Застосовано базові правила нормалізації CSS. Обчислені стилі основних елементів перевірено за допомогою Chrome DevTools.

## Перевірка результату
Сторінку перевірено у браузері Google Chrome. За допомогою Chrome DevTools перевірено відображення таблиці, застосування локального шрифту, вирівнювання тексту, межі та обчислені стилі основних HTML-елементів.

Інше браузерне середовище для порівняння результатів не використовувалося.
